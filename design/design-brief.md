## 📋 Design Brief

| Field | Value |
|-------|-------|
| **Project** | ITravelista PH |
| **Date** | 2026-08-13 |
| **Mode** | GUI (Mobile-first Web PWA) |

### Audience & Objective
| Parameter | Value |
|-----------|-------|
| **Audience Profile** | Filipino tourists (aged 20–45), casual/mobile-first, seeking hassle-free travel planning and visa preparation |
| **Primary Objective** | Home Dashboard: Instant view of travel readiness, quick access to Visa Assistant, Checklist, and Budget Planner |
| **Interaction Complexity** | Medium — interactive header drawer/dropdowns, SVG donut gauge, trip cards |

### Visual Direction
| Parameter | Value |
|-----------|-------|
| **Emotional Tone** | Warm/Organic & Inspiring — tropical travel imagery, rich deep teal branding, friendly cursive tagline |
| **Data Density** | Medium — clean mobile cards, thumb-friendly touch targets (min 44px) |
| **Content Strategy** | Real copy for PH travel (Japan, Singapore, Philippines), PHP currency (₱) |
| **Reference Anchors** | PRD design mockup (`prd/prd-desccription.jpeg`), Airbnb/TripIt modern mobile aesthetics |

### Navigation & Menu Structure
| Parameter | Value |
|-----------|-------|
| **Primary Nav Pattern** | Fixed Bottom Navigation Bar (5 tabs: Home, My Trips, Checklist, Assistant, Profile) + Left Side Drawer |
| **Main Menu Items** | Home, My Trips, Visa Assistant, Smart Checklist, Budget Planner |
| **Header Elements** | Hamburger Menu (left), Branded Logo + Cursive Tagline ("From Dreaming to Departing"), Notification Bell (right) |
| **Search Placement** | Prominent pill-shaped search input embedded in Hero section |

### Brand Identity
| Parameter | Value |
|-----------|-------|
| **Primary Color** | Deep Teal `#008080` |
| **Primary Hover / Dark** | `#006B6B` |
| **Primary Light** | Soft Aqua `#E0F2F1` |
| **Background App** | Off-White `#F8F9FA` |
| **Surface Card** | Pure White `#FFFFFF` |
| **Typography** | Inter (body/headers), **Dancing Script** (cursive brand tagline) |
| **Brand Voice** | Friendly, encouraging, reliable travel companion ("From Dreaming to Departing") |
